## 🌿 About Hikmet

Hikmet is a multilingual, AI-powered chat for thoughtful conversations about Islam and everyday life. Bring a question, a doubt, or something that feels like an obstacle between you and Allah. Hikmet is designed to help you reflect with compassion and without judgment.

## ✨ What you can do

- **Chat in 12 languages.** Hikmet detects your browser language automatically.
- **Reflect at your own pace.** The typing indicator shows when a reply is on its way. You can stop a reply, and Hikmet runs one AI request at a time.
- **Make yourself comfortable.** Use light or dark mode on a phone, tablet, or desktop. You can also add Hikmet to your home screen as a progressive web app (PWA).
- **Pick up where you left off.** The app saves conversation history in your browser. Chat requests go through the server to generate replies.

## 🤝 AI and sensitive questions

Hikmet uses Google Gemini. The chat includes safeguards for personal fatwa requests, crisis situations, and other sensitive topics, alongside checks on generated replies. For a ruling specific to your circumstances, consult a qualified scholar.

## 🛠️ Development and deployment

Hikmet uses HTML, CSS, and JavaScript, with a server-side chat endpoint on Vercel.

1. Import this repository as a Vercel project.
2. Set `GEMINI_API_KEY` in the Vercel project’s environment variables. Keep the key server-side.
3. Deploy the project. To run the build locally, use `npm run build` from the repository root.
